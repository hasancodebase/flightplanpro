What Is a TMI Number in Aviation? NAT Track Message Number Explained

A TMI is the Track Message Identification number of a North Atlantic track message. It is a three-digit number based on the Julian calendar date for which that track system (the OTS) is effective. In plain terms, it is the day number of the year: 16 January is 016, and 22 October 2026 is 295.

What the TMI is used for

Crews, dispatchers and controllers use it to confirm they are all working from the same version of the track message. When an oceanic clearance on an organised track is read back in abbreviated form, the readback includes the TMI of the current message. If the TMI is not available or is incorrect, air traffic services issue a full route clearance and ask for a full readback.

How to work it out

Count the days from 1 January, counting 1 January as day 1, and write the result with three digits. Add one to every date after February in a leap year.

Re-issued messages

If anything affecting the entry or exit points, the routes or the flight level allocation changes, the whole message is re-issued, and a letter is added to the TMI. A re-issue of 032 becomes 032A.

Always check the message

The date shown in the track message is the authority. This page explains the numbering only. To convert any date, use the TMI calculator, and read the full explanation of the message in the NAT track message guide.

FAQ

What does TMI stand for in aviation?

Track Message Identification. It identifies a North Atlantic track message.

Is the TMI the same as the date?

It is based on the Julian calendar date, written as the day number of the year with three digits, such as 295 for 22 October 2026.
